# OpenLabels Codebase Review Report

**Date**: 2026-02-25
**Scope**: Full application (~200k lines across backend, frontend, Rust extensions, migrations, tests)
**Method**: 20 parallel deep-review agents, each assigned a logical section of the codebase
**Categories**: Security, Errors & Omissions, Non-Scalable Design, AI Slop, Log Coverage, Test Coverage

---

## Executive Summary

The review identified **~180 findings** across the entire codebase. The most concerning patterns are:

1. **Security**: Multiple path traversal vectors, XSS injection points, dev-mode bypasses reachable on non-localhost, disabled TLS certificate validation, and SQL injection surface area
2. **Data integrity**: Race conditions in the worker pool, distributed locking using non-deterministic `hash()`, unbatched full-table copies in migrations, and non-atomic flush operations
3. **Test coverage**: Zero frontend tests, zero migration tests, security tests that are disabled or vacuous, and 14 of 21 CLI modules untested
4. **AI slop**: 17 of 20 migration revision IDs are synthetic hex patterns (never generated by Alembic), a bogus merge node, and near-complete duplication of two frontend form pages

Below, findings are organized by **application area**, with items sorted by severity within each section.
